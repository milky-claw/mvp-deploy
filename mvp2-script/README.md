# Price Monitor Script

Simple CLI tool to track arbitrage opportunities.

## Quick Start

```bash
# List opportunities
python3 price_monitor.py list

# Add new opportunity
python3 price_monitor.py add "Item Name" 10 50 "https://example.com"

# Analyze opportunities
python3 price_monitor.py analyze
```
